## Finding (verified in CI, run 43155745910)

Two ways to turn "a shape drawn on a face" into a block or a pocket:

| | Path A: split the face, then offset the patch | Path B: sketch on the face, then extrude |
|---|---|---|
| Commands | `sketch.create` (XY), draw, `sketch.finish`, `solid.split_face` with `sketch`, `solid.offset_face` | `sketch.create` with `{"plane": {"face": [x,y,z]}}`, draw, `sketch.finish`, `solid.extrude` with `operation` `join` (boss) or `cut` + `direction: negative` (pocket) |
| Rectangle | Volume right, but the four lines extend across the whole face: **9 pieces, 14 faces**, not 2 | Volume exact (+1000 boss, -600 pocket), **11 faces**, clean |
| Circle | Volume exact | Volume exact |

**Recommendation: build the Phase 3 gesture on Path B.** It is the engine's own boss/pocket path
and leaves no leftover faces. Path A needs a SolidCraft change (treat a closed sketch loop as an
island, not as cutting lines) and is not needed for the gesture. Pin the leftover behaviour: the
Path A tests assert 14 faces on purpose, so a SolidCraft change shows up as a test failure.

## Consequences for the tools crate (not done)

- `crates/tools` has `Command::extrude_new` (operation `new`) only. Add `extrude_join` and
  `extrude_cut` (with `direction`), and a face-sketch command builder for
  `sketch.create` with `{"plane": {"face": [x,y,z]}}`. Add each id to `ENGINE_COMMANDS`.
- Push/Pull on a face with a drawn profile should emit `sketch.finish` then `solid.extrude` with
  `join` (pulling out) or `cut` (pushing in), chosen by the sign of the drag. This is the partner's
  profile-pull work extended: see "Branches".
- Plain `Push/Pull` on an existing face stays `solid.offset_face` (the engine's tests and ours prove it).

## Not verified

  matched world X and Y there, which may not hold elsewhere).
- Face-pull when the patch touches a face edge, or overlaps an existing boss.
- Undo grouping (`edit.checkpoint`), rebuild time on hundreds of features.
- The kernel is mid-migration to SMLib: rerun `face_pull.rs` when the SolidCraft pin moves.
